# Lore files

Canon setting notes, chapter citations, and non-canon game additions for Tapaia will live in this directory.

Everything here is released under the same **GNU GPL v3** as the rest of the project (see the root [LICENSE](../../LICENSE)), consistent with [*Snowmoon*](https://vitalik.eth.limo/snowmoon/) by Vitalik Buterin.

Planned contents:

- A canon codex extracted from the novel (with chapter citations)
- Clearly labeled non-canon additions used by the game
- Place, institution, and device sheets safe for everyday-Veridia play (no war plot)

No lore files have been published yet. Contributions should separate canon from design choices and never invent canon without marking it.
