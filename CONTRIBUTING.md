# Contributing to Tapaia

Thanks for interest in contributing. The project is in **design phase**; code is not the main focus yet.

## Ways to help

- Review and improve [docs/design-doc.md](docs/design-doc.md) (open decisions, clarity, lore accuracy against *Snowmoon*)
- Propose lore files under [docs/lore/](docs/lore/) with clear canon vs design-choice labels
- When code lands: issues, patches, and tests against the published design

## Rules of thumb

1. **Everyday Veridia only.** No war, military, or Kungaupei plot arcs.
2. **Original characters only.** No canon characters as players or NPCs.
3. **Don't invent canon.** Mark anything the book doesn't specify as a design choice.
4. **GPL v3.** Contributions are licensed under GPL-3.0. AI prompts and harness belong in `prompts/`.
5. **No financial advice or price talk** in project materials. Tokenomics are placeholders.
6. **Credit and disclaimer** stay intact: *Snowmoon* credit, and the non-affiliation notice in the README.

## Process

1. Open an issue or discussion for design changes before large edits.
2. Keep PRs focused and reference the design-doc section they affect.
3. Do not commit secrets, private keys, API keys, or personal market notes.

## Contact

Community channels will be listed here once the hub exists. Until then, use GitHub issues on this repository (once it is published).
