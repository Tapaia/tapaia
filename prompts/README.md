# AI prompts and harness

System prompts, NPC sheets, GM instructions, summarizers, paraphrasers, and the task-specific harness used to run Tapaia's AI layer will be published here.

[*Snowmoon*](https://vitalik.eth.limo/snowmoon/) is GPL v3 and asks derivative projects to open-source "the pipeline (AI prompts, scripts, task-specific harness, etc) and other non-commodity materials." This directory is how we meet that expectation.

All material here is **GNU GPL v3** (see the root [LICENSE](../LICENSE)).

Nothing has been published yet. When prompts land, each should note the model/version it targets and avoid war plots or canon-character impersonation per the project ground rules.
